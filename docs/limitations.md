# Limitations

Early recordings are presumed healthy from a frozen dataset-level policy, not proven
fault-free. Test Set 2 does not supply a precise physical fault-onset timestamp in this
repository. Terminal-relative warning time is therefore not physical lead time.

G6's official rule is any approved feature on any channel. This is sensitive to
multiple comparisons and regime/noise changes. Stricter G6 alternatives are reported
only as exploratory sensitivity analyses. Candidate nodes and edges are association
evidence, not causal localization. Channel units remain explicitly unknown until the
bundled source metadata is verified.

No automatic scientific success claim is produced. Negative controls test dependence
on chronology and correspondence but do not establish physical validity.

> The benchmark evaluates the predictive and anomaly-detection behaviour of a frozen
> software method. It does not validate MCIFT as a physical theory.
